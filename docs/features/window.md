# 窗口调整

自由调整目标窗口的显示比例与超高分辨率，突破物理屏幕尺寸限制，满足摄影构图需求。

## 选择目标窗口

::: info 支持的游戏
程序默认选择《无限暖暖》作为目标窗口。同时兼容多数窗口化运行的其他现代游戏，如：
- 《最终幻想14》
- 《模拟人生4》
- 《永劫无间》
- 《鸣潮》
- 《明日方舟：终末地》
- 《异环》

如需调整其他窗口，可通过**右键单击悬浮窗或托盘图标**在菜单中选择窗口，**务必将游戏设置为窗口化运行**。
:::

## 比例预设

| 比例 | 适用场景 |
|:--|:--|
| 21:9 | 宽屏，电影感构图 |
| 16:9 | 标准横屏 |
| 3:2 | 经典相机比例 |
| 1:1 | 方形构图 |
| 3:4 | 小红书推荐比例 |
| 2:3 | 人像竖拍 |
| 9:16 | 抖音短视频 |

## 分辨率预设

| 预设 | 等效基准 | 总像素数 |
|:--|:--|:--|
| Default | 跟随屏幕 | — |
| 1080P | 1920×1080 | 约 207 万 |
| 2K | 2560×1440 | 约 369 万 |
| 4K | 3840×2160 | 约 830 万 |
| 6K | 5760×3240 | 约 1870 万 |
| 8K | 7680×4320 | 约 3320 万 |
| 12K | 11520×6480 | 约 7460 万 |

::: tip 分辨率的计算逻辑
程序先按选定的分辨率预设确定总像素数，再按选定的比例重新分配宽高。
例如：**8K + 9:16** > 输出 **4320×7680**，总像素数与 8K 相近。

**Default** 不设定像素量，按当前比例取屏幕内可容纳的最大尺寸。
:::

::: warning 性能说明
分辨率越高，对显存、内存和虚拟内存的消耗越大。RTX 3060 12G + 32G 内存的环境下，12K 分辨率会出现明显卡顿。如遇游戏崩溃，可通过任务管理器确认资源瓶颈，或适当增加虚拟内存。
:::

## 自定义预设

比例与分辨率预设均可在**设置 > 悬浮窗 > 菜单设置**中增删，也可拖拽调整顺序。

- **比例**：按 `宽:高` 填写，如 `16:9`、`4:5`。
- **分辨率**：按 `宽x高` 填写，如 `1920x1080`；也可使用 `4K`、`1080P` 这类简写。

新添加的预设排在列表末尾，可再拖到常用位置。

## 辅助功能

当调整后的窗口尺寸超出物理屏幕时，可根据需求开启以下功能辅助画面观察与操作：

### 预览窗

类似 Photoshop 的导航器，在独立浮窗中实时预览超出屏幕的完整画面，支持滚轮缩放与拖拽移动。

### 叠加层

类似 Magpie 的反向缩小版，将超出屏幕的大窗口捕获后全屏等比缩小渲染，并通过动态位置同步，保持超大分辨率下的鼠标点击与交互体验。

### 黑边模式

在窗口底部铺设全屏黑色背景，遮蔽桌面内容，为非屏幕原生比例提供纯净的沉浸式体验。
