# 图库

本地照片与视频的浏览、筛选与整理工具。

## 浏览与筛选

- **视图**：网格、瀑布流、列表、自适应（每行等高铺满，保留原图比例）。
- **日期分组**：按月份或日期分段显示，仅网格与自适应视图可用。
- **筛选**：文件夹、标签、来源、文件类型、图片形状（横 / 竖 / 方）、评分、弃置标记、主色调、日期范围、文件名，可组合使用。
- **排序**：创建日期、名称、分辨率、大小。

## 选片与整理

- **评分与弃置**：支持 1~5 星评分与"弃置"标记，可一键过滤废片并批量清理。
- **拖拽整理**：选中后可拖拽至左侧文件夹移动文件，或拖拽至标签栏添加标签。
- **剪贴板**：支持将文件复制到系统剪贴板，也可将系统剪贴板中的截图直接粘贴导入图库。
- **选择**：支持全选、反选与批量操作。

## 详情面板与大图

选中照片或视频后，右侧面板显示主色调、分辨率、文件大小、创建时间、自定义描述与直方图。

双击进入大图模式（触摸操作为单击），支持缩放、视频播放与连续浏览。

## 浏览性能

在十万张量级的目录上实测，滚动浏览、加载速度与内存占用均处于正常水平。

- 只渲染当前视口附近的卡片，单帧渲染量与照片总数无关。
- 照片按页按需加载，切换筛选或排序时也只取回当前视口附近的页。
- 滚动过程中只解码缩略图，停稳后才逐张替换为原图，滚动不会被解码阻塞。

## 文件变化与标注保留

- **目录监听**：监控目录内的增删改会实时反映到图库。程序启动时还会通过 NTFS 变更日志补上关闭期间的改动；网络目录不支持这种方式，改为重新扫描。
- **移动与重命名**：在资源管理器中移动或重命名文件，图库不会立刻丢弃它的标注，而是保留 30 天。期间把文件放回原处，标签、评分与描述会自动接续。
- **复制与另存**：新路径作为新记录入库。若内容与已有照片完全相同，会一次性继承标签、评分与描述，之后两份各自独立。

## 网络存储

支持网络共享文件夹（UNC 路径，如 NAS 或局域网共享目录）。

目录暂时不可达时会跳过监听与扫描，不会因此把其中的照片误标为缺失。Windows 回收站不支持 UNC 路径，删除网络位置上的文件会直接永久删除。

## 手机与平板访问

在同一局域网内用手机或平板浏览器打开图库，会自动切换为适合触摸操作的紧凑布局，支持滑动切换与双指缩放。详见 [局域网访问](./lan.md)。

## 《无限暖暖》扩展

- **相机参数**：自动解析照片的拍摄参数，可随时复制相机参数码以导入游戏。
- **染色码管理**：支持记录与复制服饰染色码，方便搭配管理与分享。
- **照片地图**：在大地图上按拍摄位置标注照片。悬停可预览照片卡片，点击可跳转至大图模式。
