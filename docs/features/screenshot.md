# 超清截图

捕获目标窗口的当前画面，输出尺寸跟随窗口当前的比例与分辨率。

## 游戏内置相机与程序截图

两者的画面来源不同，输出也不同。

### 游戏内置相机（推荐）

以《无限暖暖》的"大喵相机"为例，画面由游戏自身渲染输出。拍摄时游戏会暂停渲染，可避免运动模糊和时间性锯齿，同时会保留游戏照片的元数据。

点击悬浮窗中的"游戏相册"可直接打开游戏相册目录。

### 程序截图

直接捕获目标窗口的画面，输出分辨率与窗口当前尺寸一致。默认快捷键 `F11`，也可点击悬浮窗中的"截图"按钮。

适用于游戏内置相机无法保存当前超高分辨率画面，或需要截取其他窗口时。

::: warning 窗口超出屏幕时的捕获问题
部分游戏（如《最终幻想14》《模拟人生4》）在窗口尺寸超出物理屏幕时，游戏引擎只渲染和更新屏幕范围内的画面，导致截图与预览只有可见区域的内容。

可在**设置 > 窗口控制**中开启「超屏窗口捕获兼容」，或直接开启[叠加层](./window.md)功能规避。
:::

## 截图设置

- **格式**：PNG（默认，无损）或 JPEG（固定为最高质量）。日常使用推荐 JPEG，保存更快、占用空间更小；需要无损后期时再选 PNG。
- **无边框捕获**：只捕获窗口客户区，不含标题栏与窗口边框。

## 输出位置

截图与录制共用同一个输出目录，默认保存至系统"视频"文件夹下的 `SpinningMomo` 目录，可在**设置 > 输出目录**中修改，也可按目标窗口标题自动建立子目录。

保存完成后会弹出通知，点击"查看"可直接打开文件。

## HDR

系统开启 HDR 时可保存为 Ultra HDR JPEG，并可选同时保存一份无损 JXR 底片。详见 [HDR 支持](./hdr.md)。

## 实验性功能

悬浮窗「高级摄影」中的长曝光（多帧叠加）为实验性功能，局限性较大，后续可能调整或移除。
