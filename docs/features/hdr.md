# HDR 支持

在 Windows 开启 HDR 时，捕获高动态范围（HDR）的截图与视频。

## 开启方式

1. 确认系统显示设置中已开启 **Windows HDR**
2. 打开**设置 > 捕获与导出 > HDR**，开启对应功能

## HDR 截图

### Ultra HDR JPEG

基于增益图（Gain Map）技术的标准图像格式，兼顾高动态显示与多平台兼容：

- **支持 HDR 的设备**：在主流手机相册、现代浏览器及小红书等平台上，直接呈现明亮通透的高光效果；
- **普通 SDR 设备**：在未适配 HDR 的屏幕或应用中，自动作为普通照片正常显示，画面不会发灰。

### 无损 JXR（可选）

开启「同时保存 JXR」后额外生成的无损格式文件。以 16 位浮点（FP16）直接记录游戏输出的原始动态范围与色彩，适合作为高规格原片底片。

专为导入 Photoshop 进行后期精修与深度调色设计（在 Photoshop 中打开需先安装[微软官方 JPEG XR 插件](https://www.microsoft.com/en-us/download/details.aspx?id=52369)）。

## HDR 录制

录制为 **HEVC HDR10 (10-bit)** 视频格式。

::: warning 录制配置要求
需在设置中同时选择 **GPU 编码器** 与 **H.265 (HEVC)** 格式（不支持 CPU 编码和 H.264）。
:::
