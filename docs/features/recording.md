# 视频录制

录制目标窗口的画面与音频，输出分辨率与当前窗口尺寸一致。

## 开始与停止

点击悬浮窗中的"录制"按钮开始，再次点击停止。默认快捷键 `F8`。

## 录制设置

- **帧率**：默认 60 FPS。
- **码率控制**：质量优先（默认，质量 80）、固定码率或手动 QP。
- **编码格式**：H.264 或 H.265。
- **编码器**：自动（默认，优先显卡硬件编码）、强制硬件编码或 CPU 软件编码。
- **音频源**：系统音频（默认）、仅游戏音频，或关闭。
- **鼠标指针**：可选是否录进画面。
- **无边框捕获**：只捕获窗口客户区，不含标题栏与窗口边框。

## 尺寸变化自动切段

录制过程中改变窗口比例或分辨率时，自动结束当前片段并按新尺寸继续录制，避免中途改尺寸导致整段视频变形或裁切。可在设置中关闭。

## 输出位置

输出为 MP4 文件，保存位置与截图共用同一个输出目录。

## HDR

开启后录制为 HEVC HDR10 视频，需配合显卡硬件编码与 H.265 格式。详见 [HDR 支持](./hdr.md)。

## 高分辨率录制

::: warning 硬件与编码限制
- **硬件要求**：6K / 8K 录制对显卡编码器和磁盘写入速度要求较高。
- **编码格式**：显卡硬件编码下 H.264 的分辨率上限约为 4096（NVIDIA、AMD、Intel 的硬件编码器均有此限制），录制 4K 以上需改用 **H.265**（上限约 8192）。
:::

## 与其他录制工具

**更低占用**：画面捕获与编码走 Windows 原生管线并优先使用显卡硬件编码，不做场景合成与推流，显存与系统占用低于通用录屏工具。

推流直播、多音轨分离、多图层混流等场景，需使用 OBS 等专业工具。
