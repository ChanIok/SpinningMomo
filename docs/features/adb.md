# ADB 模式

ADB（Android Debug Bridge，安卓调试桥）是 Android 官方提供的调试工具。通过 ADB 连接模拟器或真机，可在 PC 上控制设备分辨率，并进行截图与视频录制。

## 支持的游戏

- 《闪耀暖暖》

## 支持的设备

- **安卓模拟器**：自动识别当前运行中的 MuMu、雷电、蓝叠，无需手动配置
- **安卓真机**：需额外准备，详见下方说明

## 快速开始（模拟器）

1. **启用菜单按钮**：设置 → 悬浮窗 → 功能项，开启「ADB 模式」
2. 启动模拟器并打开游戏
3. 点击悬浮窗中的「ADB 模式」按钮，自动发现并连接

连接成功后，截图与录制的操作方式与普通模式相同。

## 录制说明

同时录制屏幕画面和游戏音频，输出为 MP4 格式。可在**设置 → ADB 模式**中调整码率（默认 40Mbps）、帧率和编码格式（H.264 / H.265）。

## 比例调整安全须知

::: warning 请选择与当前画面方向一致的比例
- **竖屏状态下**（如游戏处于竖拍模式或模拟器为手机模式）：请仅选择 **9:16、3:4、2:3、1:1** 等竖向或方形比例，**切勿切换至 16:9、21:9 等横向比例**。
- 跨方向切换比例（如竖屏强行切横屏）会导致安卓系统画面异常拉伸、旋转倒置、触控错位甚至模拟器黑屏。
- **如遇显示异常**：在悬浮窗分辨率预设中选择 **Default**，或关闭 ADB 模式，即可立即恢复设备系统默认尺寸。
:::

## 功能限制

以 MuMu 模拟器为例：

- **截图分辨率**：最大支持长边 7680px
- **录制分辨率**：最大支持长边 2560px（受安卓系统编码器限制，无法突破）

高分辨率录制建议使用模拟器自带的录屏功能。安卓真机通常不受录制分辨率限制。

## 连接安卓真机

**前置准备**

1. 下载 [Android Platform Tools](https://developer.android.com/tools/releases/platform-tools?hl=zh-cn)，解压后获得 `adb.exe`
2. 在手机上开启**开发者模式**，并启用 **USB 调试**

**连接步骤**

1. 用 USB 线连接手机与电脑
2. 打开**设置 → ADB 模式**，开启「自定义 ADB 路径」，选择 `adb.exe` 所在位置
3. 在设备列表中选择已连接的手机，或手动填写 IP 和端口进行无线连接
