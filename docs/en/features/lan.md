# LAN Access

Browse and manage your gallery directly on a phone or tablet over the same local network.

## Connecting

1. Go to **Settings > LAN Access** and toggle the switch on
2. Scan the QR code with your mobile device, or open the displayed URL in a browser

::: warning Network Requirement
Your mobile device and PC must be connected to the same local network (same Wi-Fi/router).
:::

## Mobile Features

- Browse gallery assets and inspect photo/video details
- Touch gestures: swipe to navigate, pinch to zoom, and long-press for multi-selection
- Download individual files or export selected media as a ZIP archive

## Security

Each access link includes an authentication token. You can click **Reset Token** in settings at any time to invalidate old links. Recommended for use only on trusted home networks.
