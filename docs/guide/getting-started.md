# 安装与运行

本页面将带你完成初次配置，并拍出你的第一张超清竖构图。

## 下载程序

| 下载源 | 链接 | 说明 |
|:--|:--|:--|
| **GitHub** | [点击下载](https://github.com/ChanIok/SpinningMomo/releases/latest) | 国内访问可能受限 |
| **百度网盘** | [点击下载](https://pan.baidu.com/s/1UL9EJa2ogSZ4DcnGa2XcRQ?pwd=momo) | 提取码：`momo` |

提供两种版本：

- **安装版（.exe）**：含安装向导，推荐大多数用户使用，支持卸载管理
- **便携版（.zip）**：免安装，适合不想写入注册表的用户

::: warning 便携版使用注意
请**右键压缩包 → 全部解压缩**，将所有文件提取到一个单独的文件夹中，再运行其中的 `SpinningMomo.exe`。

直接在压缩包内双击运行，或只单独提取 exe 文件，会导致程序缺少必要资源而无法正常使用。
:::

### 系统要求

::: warning 运行环境
- **操作系统**：Windows 10 1903 (Build 18362) 或更高版本（64 位）
- **WebView2**：主界面依赖 [Microsoft WebView2 运行时](https://developer.microsoft.com/zh-cn/microsoft-edge/webview2/)（**≥ 123.0.2420.47**），现代 Windows 通常已内置
:::

## 首次启动

运行程序后，可能会弹出以下系统提示：

::: warning Windows 安全提示
- **UAC 提示**：点击 **是** 授予管理员权限（程序调整游戏窗口必须使用此权限）
:::

## 初始配置向导

首次启动后，程序会进入配置向导：

**第 1 步**：选择界面语言和主题（深色/浅色/跟随系统）

**第 2 步**：确认目标窗口标题

配置完成后，程序悬浮窗将自动出现在屏幕上。

::: tip
按 **`` Ctrl + ` ``**（键盘左上角反引号键，数字 `1` 左边）可随时隐藏/显示悬浮窗。
:::

## 游戏内前置设置

在开始拍摄前，进入《无限暖暖》确认以下设置：

- **显示模式**：选择 **窗口模式**
- **拍照 - 照片画质**：选择 **窗口分辨率**

## 拍出第一张超清竖构图

1. 打开大喵相机进入摄影模式，找好场景和角色位置
2. 在悬浮窗中选择比例 **9:16** 与分辨率 **8K**（性能较低可选 4K / 6K）
3. 画面超出屏幕属正常现象，可在悬浮窗中开启 **叠加层** 或 **预览窗** 辅助预览
4. 按空格键拍照，完成后在悬浮窗中点击 **重置** 恢复窗口大小

::: tip 提示“未找到目标窗口”？
请**右键悬浮窗**（或托盘图标），在菜单中重新选择目标窗口。
:::
